# v1.0.0 — 6 ноября 2026

Первый релиз помощника покупателя автомобиля: каталог исторических объявлений,
заявки и подбор, сохранённые кандидаты, ML-оценки и аналитика.

## Основание релиза

Основная реализация, упаковка и проверки слиты в `main` через
[PR №1](https://github.com/troublegale/research-graph/pull/1),
[№2](https://github.com/troublegale/research-graph/pull/2) и
[№3](https://github.com/troublegale/research-graph/pull/3) после внешних Approve.
Последний коммит слияния: `cfa49ec36068b2b1af51c3d5677b04ea6912ee09`.

По согласованию с автором тег `v1.0.0` указывает на релизную ветку
`feature/release-1.0.0`: она включает слитую реализацию, итоговую документацию
ревью и согласованный номер версии пакета, CLI и OpenAPI. Для переноса этих
релизных изменений в защищённую `main` используется отдельный PR.

## Исправления по ревью

- Атомарная регистрация версии модели при параллельных первых прогнозах.
- Подгрузка и открытие заявок после первой сотни.
- Единая нормализация целевой цены CSV перед вычислением метрик.

[Полный отчёт: замечания, исправления, проверки, ответы и одобрения](../review_fixes.md).
[Проведённые ревью двух PR коллеги](../peer_reviews.md).

После функциональных исправлений локально прошли 115 тестов с SQLite
и PostgreSQL, покрытие — 99,49%. В CI проверяются Linux/Windows,
Python 3.12/3.13, PostgreSQL, Docker и браузерные сценарии.

## Данные и модель

Датасет и модель остаются локальными артефактами, в тег не включены.
Источник — объявления 2023 года. CatBoost обучен на выборке 50 тысяч
уникальных объявлений; test MAE — 334 061 ₽.
Прогноз относится к историческим ценам предложений, не подтверждает цену
сделки, состояние машины или её текущую доступность.

## Запуск

```bash
git checkout v1.0.0
uv sync --locked
uv run rg migrate
uv run rg seed
uv run rg serve
```

Для ML-прогнозов нужен `artifacts/model.zip`: загрузить собственный архив
или выполнить подготовку данных и обучение по README. Без модели каталог
и заявки работают. Docker-вариант: `docker compose up --build -d --wait`.
